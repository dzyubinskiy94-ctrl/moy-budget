# Мой бюджет — личный учёт доходов и расходов

Приложение работает локально на устройстве: учёт в рублях, быстрые расходы, категории, лимиты, резервные копии JSON и CSV-выгрузки.

## Самая короткая установка
1. Откройте опубликованный сайт через GitHub Pages.
2. Если страница не открывается, в репозитории GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. В настройках **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions** (если ещё не включено). После пуша `main` workflow Pages публикует сайт. Если первый запуск завершился ошибкой включения Pages, включите Pages в настройках вручную и повторите workflow.
4. Откройте `https://USERNAME.github.io/moy-budget/` в Chrome на Android → меню `⋮` → **Установить приложение** / **Добавить на главный экран**.
5. Для настоящего APK: GitHub → **Actions → Сборка Android APK** → выберите успешный запуск → **Artifacts → MoyBudget-Android-APK**. Скачайте архив, распакуйте `app-debug.apk` и установите его на телефон.

## Важно
- **Публично размещается только код приложения.** Ваши операции остаются в локальном хранилище браузера или Android WebView и не публикуются в GitHub.
- Отсутствует облачная синхронизация. Регулярно делайте резервную копию: **Настройки → Резервная копия**. Переход с веб-версии на APK требует экспорта из одной версии и импорта в другую.
- APK — **debug-сборка** для личной установки, не публикация в Google Play. Чтобы устанавливать обновления поверх старых APK, потребуется стабильный ключ подписи; для первой установки debug-APK подходит.
- Для Android проекта нужна Java 17 и Android SDK 35. Workflow делает сборку на GitHub Actions без вашего компьютера.


### Виджет Android (версия 1.1)

На главном экране телефона удерживайте свободное место → «Виджеты» → «Мой бюджет».
Кнопка «+ Расход» открывает форму, 100/300/500 ₽ подставляют сумму.
После создания в программе избранных быстрых расходов виджет показывает до трёх из них: нажатие сразу записывает расход и открывает приложение с возможностью отмены.
Данные по-прежнему хранятся в WebView localStorage, а не в коде или GitHub.

**Обновление предыдущего отладочного APK:** подпись сборки на разных машинах может различаться. Перед переустановкой сохраните резервную копию JSON. Если система требует удалить старую версию, сначала сделайте резервное копирование.
