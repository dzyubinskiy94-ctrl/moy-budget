# Мой бюджет

Личный офлайн-трекер финансов с доходами, расходами, аналитикой, быстрыми операциями, категориями и лимитами.

## Веб-приложение

[Открыть Мой бюджет](https://dzyubinskiy94-ctrl.github.io/moy-budget/).

На Android: Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Для публикации используется GitHub Actions: `.github/workflows/deploy-pages.yml`.

## Конфиденциальность

**В репозитории только исходный код**, без реальных финансовых операций. Данные сохраняются в localStorage текущего браузера/устройства. Нет облачной синхронизации, поэтому регулярно создавайте резервные копии JSON через настройки приложения. При переходе между браузером и APK нужно перенести JSON-файл вручную.

## Android

GitHub Actions собирает Android APK при обновлениях папки `android/`. APK доступен в разделе Actions → Сборка Android APK → Artifacts. Это отладочная сборка, предназначенная для личной установки.
